# Triage Decision Cues

## Escalate sooner when

- multiple users are blocked
- the report is a clear regression
- the issue affects a release-critical path
- the issue has fresh reproduction details and no owner yet

## Ask for more detail when

- the expected versus actual behavior is unclear
- there is no environment or version information
- the issue title is broad but the body is vague

## Consider deferring when

- the issue is real but low impact
- there is a known workaround
- the queue already contains a higher-priority incident or regression

## Consider closure when

- the report is clearly no longer reproducible
- the issue duplicates an actively tracked ticket
- the requester never responded after a reasonable follow-up window
