# Maintainer Context

Use this file to give the installed Agent local context about the repository or queue you want it to review.

For the first run, keep it simple:

- Repository: `agentpm-dev/agentpm-examples`
- Maintainer: `local-maintainer`
- Goal: understand what the generated Harness workspace installed and how to run it.
- Constraint: do not post comments, close issues, or perform write actions unless explicitly asked and approved.

Replace this content with your real project context once the scaffold is running.
