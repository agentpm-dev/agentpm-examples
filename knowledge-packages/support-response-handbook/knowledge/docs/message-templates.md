# Message Templates

Use these as drafting patterns, not fixed scripts. Replace placeholders with case-specific details.

## Acknowledgement while investigating

```text
Thanks for flagging this. I can confirm we are reviewing the issue affecting {{workflow_or_surface}}.

What we know right now:
- {{confirmed_fact_1}}
- {{confirmed_fact_2}}

What happens next:
- {{next_internal_action}}
- We will follow up by {{next_update_commitment}}
```

## Clarification request

```text
Thanks for the report. To narrow this down, could you share:

- {{requested_detail_1}}
- {{requested_detail_2}}
- {{requested_detail_3}}

If easier, a short reproduction sequence or screenshot is enough.
```

## Escalation notice

```text
I’m escalating this to {{owning_team}} because it needs a deeper review than standard support handling.

Current status:
- {{impact_summary}}
- {{what_has_been_checked}}

Next update:
- {{next_update_commitment}}
```

## Resolution follow-up

```text
Following up with an update on {{issue_summary}}.

We have:
- {{resolution_detail_1}}
- {{resolution_detail_2}}

If you still see the issue after {{verification_step}}, reply here and we will continue the thread.
```
