# Harness Config

`agentpm.harness.json` is the consumer-owned runtime configuration file for `agentpm harness`. It is optional, source-control friendly, and not packaged with the Agent.

If the file exists, `version` is required. Version 1 is strict: unknown fields are rejected except for open ID-keyed registries/maps and provider-specific `model.options`.

All relative paths resolve from the discovered workspace root, not from the config file's own directory.

## Minimal Config

```json
{
  "version": 1
}
```

A missing config file is equivalent to version-1 defaults plus CLI, SDK, and environment values.

## Implementation Descriptors

Custom model providers, embedding providers, Hooks, Knowledge runtimes, Memory runtimes, and approval controllers use a shared implementation descriptor.

Process-backed:

```json
{
  "type": "process",
  "command": "python",
  "args": ["runtime/provider.py"],
  "cwd": ".",
  "env": ["PROVIDER_API_KEY"],
  "startup_timeout_ms": 15000,
  "request_timeout_ms": 120000,
  "restart": {
    "max_attempts": 1,
    "backoff_ms": 250
  }
}
```

Host-backed:

```json
{
  "type": "host",
  "request_timeout_ms": 120000
}
```

`process` implementations speak the `agentpm-service` protocol over persistent stdin/stdout. `host` implementations are supplied by a connected machine/SDK client. Harness never silently replaces an unavailable configured implementation.

## Model And Provider Config

Built-in model providers are:

- `openai`
- `anthropic`
- `ollama`

Other `model.provider` values must match `providers.models`. Model IDs are open strings and are not enumerated by AgentPM. `model.options` is provider-specific JSON and must not contain secrets.

## Hooks

Version-1 Hook IDs:

- `before_model_request`
- `before_tool_selection`
- `before_tool_call`
- `before_knowledge_request`
- `after_knowledge_retrieval`
- `before_memory_read`
- `before_memory_write`
- `before_memory_operation`

`failure_policy` is `closed` or `continue` and defaults to `closed`.

## MCP

`mcp.imports` brings external MCP servers into phase execution according to explicit scope. `mcp.exports` hosts Agent-authored outward MCP surfaces. Exported MCP surfaces are Session-owned, not Run-owned; calls to them do not become part of the active Run merely because their timing overlaps it.

## Trace And Branding

Trace defaults:

```json
{
  "trace": {
    "enabled": true,
    "level": "normal",
    "content": "redacted"
  }
}
```

`trace.level` is `minimal`, `normal`, or `verbose`. `trace.content` is `none`, `redacted`, or `full`.

Branding is limited to name, subtitle, and accent. Harness does not provide arbitrary TUI layout/theme/plugin scripting.
