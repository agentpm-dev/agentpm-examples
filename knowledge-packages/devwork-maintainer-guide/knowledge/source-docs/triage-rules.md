# Triage Rules

## Triage sequence

Start by deciding whether the issue is a bug report, feature request, workflow question, or duplicate. If the thread mixes several concerns, summarize the main blocker first and note the secondary concerns separately.

## Priority signals

Raise urgency when the report blocks normal maintainer work, breaks common repository workflows, or has clear reproduction steps showing a regression. Keep urgency lower when the issue is incomplete, speculative, or missing the basic context needed to act.
