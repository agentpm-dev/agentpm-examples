# Labeling Guide

## Label for actionability

Use labels to explain what kind of maintainer action is needed next: reproduction, design review, documentation, cleanup, or external follow-up. Prefer a small label set that helps queue owners decide where to spend time.

## Label for ambiguity

If an issue is missing details, mark that state clearly instead of silently letting it age in the backlog. When a label implies a request back to the reporter, pair it with a short comment describing exactly what is missing.
